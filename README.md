# DragAndDropGames - Auto novietošanas spēle

Šī ir izglītojoša un interaktīva 2D spēle, izstrādāta Unity vidē.
Spēlētāja uzdevums ir pareizi novietot dažādus transportlīdzekļus to attiecīgajās vietās uz laukuma.
Spēle pārbauda objektu novietojumu, izmēru un rotāciju, atskaņo skaņas efektus un vizuālus paziņojumus par pareizu vai nepareizu novietojumu.

Kad visi transportlīdzekļi ir novietoti pareizi, tiek atvērts uzvaras panelis.
